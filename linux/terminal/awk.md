# awk

разделитель по умолчанию - пробел

`awk '{print}` - выведет весь файл (или `$0`)
`awk '{print $n}` - выведет колонку под номером
`awk '{print $n, $n}` - выведет несколько колонок
`awk '{print $NF}` - выведет последнюю колонку (NF - number of fields)
`awk -F ':' '{print $1,$7}' /etc/passwd` - выведет вторую колонку с кастомным разделителем `:`
