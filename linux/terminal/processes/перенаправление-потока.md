# перенаправление

```sh
&> или &>>
program &>> both.txt
# перенаправление одного потока в другой
2>&1 # stderr to stdout
1>&2 # stdout to stderr
# перенаправление в никуда или из ниоткуда (чтобы не выводить на экран)
/dev/null
program 2>/dev/null
# так можно обнулить файл
cat /dev/null > file.txt
```
