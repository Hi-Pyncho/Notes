Массивы в Go — это базовая структура данных, представляющая собой упорядоченную коллекцию элементов **фиксированного размера** одного и того же типа.

### Основные характеристики массивов в Go:

1. **Фиксированный размер**  
   Размер массива определяется при его объявлении и **не может быть изменён** во время выполнения программы.

2. **Тип элементов**  
   Все элементы массива должны быть одного типа (например, `[5]int`, `[3]string` и т.д.).

3. **Нумерация с нуля**  
   Индексы элементов начинаются с `0`.

---

### Объявление и инициализация

```go
// Объявление массива из 5 целых чисел (все элементы = 0)
var arr [5]int

// Инициализация при объявлении
arr := [5]int{1, 2, 3, 4, 5}

// Автоматическое определение размера
arr := [...]int{10, 20, 30} // компилятор выведет [3]int

// Частичная инициализация (остальные элементы будут нулевыми)
arr := [5]int{1, 2} // [1, 2, 0, 0, 0]
```
---

### Доступ к элементам

```go
arr := [3]string{"a", "b", "c"}
fmt.Println(arr[0]) // выводит "a"
arr[1] = "x"        // изменение элемента
```

---

### Передача массивов в функции

Массивы в Go **передаются по значению**, то есть при передаче в функцию создаётся полная копия. Это может быть неэффективно для больших массивов.

```go
func modify(arr [3]int) {
    arr[0] = 99 // изменение копии, оригинал не меняется
}
```

Если нужно изменить оригинальный массив, передавайте указатель:

```go
func modify(arr *[3]int) {
    arr[0] = 99 // изменяет оригинал
}
```

---

### Длина массива

Длина массива определяется с помощью встроенной функции `len()`:

```go
arr := [4]int{1, 2, 3, 4}
fmt.Println(len(arr)) // 4
```

---

### Важно: массивы vs срезы (slices)

Хотя массивы полезны, в реальных программах чаще используют **срезы** (`slices`), потому что:

- Они **динамические** (размер может меняться).
- Более гибкие и удобные.
- Передаются по ссылке (эффективнее).

Пример среза:

```go
slice := []int{1, 2, 3} // без указания размера — это срез
```

---

### Заключение

Массивы в Go — это простая и эффективная структура для хранения фиксированного числа однотипных значений. Однако из-за их неизменяемого размера на практике чаще используют срезы.
