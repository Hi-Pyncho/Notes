В Go строки — это **неизменяемые (immutable)** последовательности байтов в кодировке **UTF-8**. Это одна из ключевых особенностей языка, и она сильно влияет на то, как с ними работать.

Разберём всё по пунктам:

---

## 1. **Основы: что такое строка в Go**

- Тип: `string`
- Неизменяема: нельзя сделать `s[0] = 'A'`
- Хранит **байты в UTF-8**, а не «символы» напрямую
- Может содержать нулевые байты (`\x00`)
- Пустая строка: `""`

```go
s := "Привет, мир!" // валидная UTF-8 строка
```

## ➕ 2. **Конкатенация строк**

### ✅ Способ 1: оператор `+`
```go
s := "Hello" + " " + "World" // "Hello World"
```
> Подходит для **небольшого числа строк**. При множестве конкатенаций — неэффективно (создаёт много промежуточных строк).

### ✅ Способ 2: `strings.Join`
```go
import "strings"

parts := []string{"Hello", "World", "!"}
s := strings.Join(parts, " ") // "Hello World !"
```
> Эффективно для **массива/слайса строк**.

### ✅ Способ 3: `strings.Builder` (лучший для циклов)
```go
import "strings"

var b strings.Builder
b.WriteString("Hello")
b.WriteString(" ")
b.WriteString("World")
s := b.String() // "Hello World"
```

Для более эффективной сборки строки, можно использовать preallocation, так как `builder` использует `slices`. и можно избежать лишних реаллокаций
```go
func concat(values []string) string {
    total := 0
    for i := 0; i < len(values); i++ {
        total += len(values[i])
    }

    sb := strings.Builder{}
    sb.Grow(total) // аллоцируем память для всей строки
    for _, value := range values {
        _, _ = sb.WriteString(value)
    }
    return sb.String()
}
```

## 🔁 3. **Преобразование в строку и из строки**

### 🔄 В строку:
- **Число → строка**: `strconv.Itoa`, `strconv.FormatInt`, `strconv.FormatFloat`
- **Байты → строка**: `string([]byte{...})`
- **Руна → строка**: `string(rune)`

```go
import "strconv"

s1 := strconv.Itoa(42)               // "42"
s2 := strconv.FormatFloat(3.14, 'f', -1, 64) // "3.14"
s3 := string([]byte{72, 101, 108, 108, 111}) // "Hello"
s4 := string('A')                    // "A"
```

> ❌ Нельзя писать `string(42)` — это даст символ с кодом 42 (`'*'`), а не `"42"`!

### 🔄 Из строки:
- **Строка → число**: `strconv.Atoi`, `strconv.ParseInt`, `strconv.ParseFloat`
- **Строка → байты**: `[]byte(s)`
- **Строка → руны**: `[]rune(s)`

```go
n, _ := strconv.Atoi("42")           // 42 (int)
f, _ := strconv.ParseFloat("3.14", 64) // 3.14 (float64)
bytes := []byte("Hello")             // []byte
runes := []rune("Привет")            // []rune — Unicode code points
```

## 📜 4. **Многострочные строки**

В Go есть **raw string literals** — строки в обратных кавычках (`` ` ``):

```go
s := `Это
многострочная
строка.

Она сохраняет
все пробелы и переносы.`
```

Особенности:
- Нет escape-последовательностей (`\n`, `\t` и т.д. не работают)
- Чтобы вставить **обратную кавычку**, её нельзя — только через конкатенацию
- Часто используется для регулярных выражений, SQL, JSON-шаблонов

Пример:
```go
query := `
SELECT name, email
FROM users
WHERE active = true;
`
```

> Для обычных строк с `\n` используйте двойные кавычки: `"line1\nline2"`.

## 🧾 5. **Форматирование строк**

### ✅ `fmt.Sprintf` — самый популярный способ
```go
import "fmt"

name := "Alice"
age := 30
s := fmt.Sprintf("Имя: %s, возраст: %d", name, age)
// "Имя: Alice, возраст: 30"
```

Часто используемые спецификаторы:
- `%s` — строка
- `%d` — целое число
- `%f` — вещественное число
- `%v` — значение в «умолчательном» виде
- `%T` — тип значения
- `%x` / `%X` — шестнадцатеричное представление

Пример:
```go
fmt.Sprintf("Hex: %x", 255) // "ff"
fmt.Sprintf("Value: %v, Type: %T", 42, 42) // "Value: 42, Type: int"
```

> 💡 `fmt.Printf`, `fmt.Println` и т.д. работают аналогично, но выводят в `os.Stdout`.

## 6. **Обращение к символам в строке**

⚠️ **Важно**: строка в Go — это **массив байтов в UTF-8**, а не массив «символов».

### ❌ Неправильно (для не-ASCII):
```go
s := "Привет"
fmt.Println(s[0]) // выводит 208 (байт!), а не 'П'
```

### ✅ Правильно — работать с **рунами** (Unicode code points):

```go
s := "Привет"
runes := []rune(s)
fmt.Println(runes[0])        // 'П' (тип rune)
fmt.Printf("%c\n", runes[0]) // П
```

### Перебор по рунам:
```go
for i, r := range "Привет" {
    fmt.Printf("Позиция (байт): %d, руна: %c\n", i, r)
}
```
Вывод:
```
Позиция (байт): 0, руна: П
Позиция (байт): 2, руна: р
Позиция (байт): 4, руна: и
...
```
> Обратите внимание: индекс `i` — это **байтовая позиция**, а не номер символа!

### Длина строки:
- `len(s)` — **число байтов**
- `utf8.RuneCountInString(s)` или `len([]rune(s))` — **число рун (символов)**

```go
s := "café" // 4 символа, но 5 байтов (é = 2 байта в UTF-8)
fmt.Println(len(s))               // 5
fmt.Println(len([]rune(s)))       // 4
```

- `unicode` / `unicode/utf8` — работа с рунами и UTF-8

## ✅ Итог: ключевые правила

1. **Строки неизменяемы** → для модификации — создавайте новую.
2. **Используйте `[]rune(s)` для работы с символами**, если есть не-ASCII.
3. **`len(s)` — байты, не символы**.
4. **Для конкатенации в цикле — `strings.Builder`**.
5. **Для форматирования — `fmt.Sprintf`**.
6. **Многострочные строки — в обратных кавычках** `` `...` ``.

Go делает работу со строками **безопасной и предсказуемой**, но требует понимания UTF-8 и различия между байтами и символами.
