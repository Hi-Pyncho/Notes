В Go числовые типы строго определены и делятся на **целые**, **вещественные (с плавающей точкой)** и **комплексные** числа. Go не делает неявных приведений между числовыми типами — даже между `int` и `int32` — что повышает безопасность и предсказуемость кода.

---

## 1. Целые числа (Integer Types)

### Специфичные по размеру типы:
| Тип | Диапазон | Описание |
|-----|--------|--------|
| `int8` | -128 до 127 | 8-битное целое со знаком |
| `int16` | -32 768 до 32 767 | 16-битное |
| `int32` | -2³¹ до 2³¹−1 | 32-битное |
| `int64` | -2⁶³ до 2⁶³−1 | 64-битное |
| `uint8` | 0 до 255 | беззнаковое (синоним: `byte`) |
| `uint16` | 0 до 65 535 | |
| `uint32` | 0 до 2³²−1 | |
| `uint64` | 0 до 2⁶⁴−1 | |

> 💡 `byte` — это псевдоним для `uint8`  
> 💡 `rune` — псевдоним для `int32` (используется для Unicode-символов)

### Архитектурно-зависимые типы:
- `int` — знаковое целое, размер **зависит от платформы**:  
  - 32 бита на 32-битных системах  
  - 64 бита на 64-битных системах (большинство современных ОС)
- `uint` — беззнаковый аналог `int`

> ✅ Рекомендуется использовать `int` по умолчанию, если не требуется конкретный размер или беззнаковость.

---

## 📏 2. Вещественные числа (Floating-Point)

| Тип | Точность | Размер |
|-----|--------|--------|
| `float32` | ~6–7 десятичных цифр | 32 бита |
| `float64` | ~15–17 десятичных цифр | 64 бита |

> ✅ **По умолчанию используйте `float64`**, если нет особых требований к памяти или совместимости.

Пример:
```go
var pi float64 = 3.1415926535
x := 2.0 // тип — float64 (без суффикса)
y := 2.0f32 // тип — float32
```

⚠️ Как и в других языках, `float` не подходит для точных вычислений (например, денег). Используйте целые (в копейках) или специальные библиотеки (`math/big`, `decimal`).

---

## 3. Комплексные числа

| Тип | Компоненты |
|-----|-----------|
| `complex64` | `float32` для real и imag |
| `complex128` | `float64` для real и imag |

Создание:
```go
c1 := 3 + 4i           // тип complex128
c2 := complex(5.0, 6.0) // то же самое
c3 := 1 + 2i32         // complex64

realPart := real(c1)   // 3
imagPart := imag(c1)   // 4
```

## 4. Константы и неопределённые типы

Go имеет мощную систему **нетипизированных констант**:

```go
const a = 42        // нетипизированная целочисленная константа
const b = 3.14      // нетипизированная вещественная константа

var x int = a       // OK: 42 помещается в int
var y float64 = b   // OK
var z byte = a      // OK, если a в диапазоне byte (0–255)
```

> ✨ Это позволяет использовать одну и ту же константу в разных контекстах без явного приведения.

Но:
```go
var n int = 1000
var b byte = n  // ❌ ОШИБКА: нельзя присвоить int → byte без приведения
```

---

## 🔁 5. Приведение типов (явное)

В Go **нет неявных числовых приведений**. Даже `int` → `int64` требует явного преобразования:

```go
var a int = 10
var b int64 = int64(a) // ✅ явное приведение

// c := a + b // ❌ ошибка: нельзя складывать int и int64
c := int64(a) + b // ✅
```

> ⚠️ Приведение может привести к **потере данных** (например, `int64` → `int8`), но Go не проверяет переполнение — будьте осторожны!

## 📦 6. Полезные пакеты

- **`math`** — математические функции (`math.Sin`, `math.Sqrt`, `math.MaxInt` и т.д.)
- **`math/big`** — произвольная точность (для очень больших чисел или точных вычислений)
- **`strconv`** — преобразование чисел в строки и обратно

Пример:
```go
import "math"

x := math.Sqrt(16) // float64
max := math.MaxInt   // максимальное значение int на текущей платформе
```

---

## ✅ Рекомендации

- Используйте `int` для индексов, счётчиков, размеров.
- Используйте `float64` для вещественных чисел.
- Не используйте `float` для финансовых расчётов.
- Всегда явно приводите типы при необходимости.
- Пользуйтесь константами — они гибкие и безопасные.

---

## Заключение

Числа в Go:
- **Строгие по типу**
- **Без неявных приведений**
- **Чётко разделены по размеру и знаку**
- **Поддерживают комплексные числа «из коробки»**

Это делает код более надёжным и предотвращает многие ошибки, характерные для C/C++ или JavaScript.
