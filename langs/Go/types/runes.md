Тип `rune` в Go — это встроенный способ работы с **символами Unicode** (а не просто байтами). Он играет ключевую роль при корректной обработке текста на разных языках, включая эмодзи, кириллицу, иероглифы и т.д.

---

### Что такое `rune`?

- `rune` — это **псевдоним** (alias) для типа `int32`.
- Он представляет **один Unicode-кодpoint** (code point) — то есть **один символ** в терминах стандарта Unicode.

```go
var r rune = 'A'        // r == 65
var emoji rune = '🙂'    // r == 128578
```

> Обратите внимание: литерал `rune` записывается в **одинарных кавычках**: `'A'`, `'я'`, `'🙂'`.

---

### Зачем нужен `rune`, если есть `string` и `byte`?

В Go:
- `string` — это **неизменяемая последовательность байтов**, закодированная в **UTF-8**.
- `byte` (синоним `uint8`) — это один байт.
- Но **один Unicode-символ может занимать от 1 до 4 байтов в UTF-8**.

Пример:

```go
s := "café" // последний символ 'é' — 2 байта в UTF-8
fmt.Println(len(s))        // → 5 (байтов!)
fmt.Println(len([]rune(s))) // → 4 (символов!)
```

Если вы перебираете строку через `for i := 0; i < len(s); i++`, вы идёте **по байтам**, а не по символам — и можете "разорвать" многобайтовый символ.

---

### Как работать со строками как с последовательностью символов?

#### 1. **Преобразование строки в срез `rune`**

```go
s := "Привет, 🌍!"
runes := []rune(s)
fmt.Println(len(runes)) // → 10
fmt.Println(runes[0])   // → кодpoint 1055 ('П')
```

Это даёт **доступ к каждому символу по индексу**.

> ⚠️ Это создаёт копию данных — может быть дорого для очень длинных строк.

#### 2. **Цикл `for range` по строке — автоматически по `rune`**

```go
s := "Hello, 世界"
for i, r := range s {
    fmt.Printf("Позиция байта: %d, символ: %c, код: %d\n", i, r, r)
}
```

Вывод:
```
Позиция байта: 0, символ: H, код: 72
Позиция байта: 1, символ: e, код: 101
...
Позиция байта: 7, символ: 世, код: 19990
Позиция байта: 10, символ: 界, код: 30028
```

> ✅ Это **самый эффективный и правильный способ** перебора строки по символам в Go.

Обратите внимание: `i` — это **индекс в байтах**, а `r` — сам `rune`.

---

### 🔹 Отличие `rune` от `byte`

| Тип    | Размер | Представляет         | Использование                     |
|--------|--------|----------------------|-----------------------------------|
| `byte` | 1 байт | Байт (`uint8`)       | Работа с сырыми данными, ASCII    |
| `rune` | 4 байта| Unicode code point   | Работа с текстом, символами       |

---

### 🔹 Полезные пакеты

- [`unicode`](https://pkg.go.dev/unicode) — проверка категорий символов:
  ```go
  unicode.IsLetter(r)
  unicode.IsDigit(r)
  unicode.ToUpper(r)
  ```
- [`strings`](https://pkg.go.dev/strings) — многие функции работают с `string`, но для сложной обработки символов часто нужно `[]rune`.

---

### 🔹 Важно помнить

- `string` в Go всегда в **UTF-8** — это гарантия языка.
- `rune` = **один логический символ**, но не всегда "видимая единица" (grapheme cluster).  
  Например, флаг 🇺🇦 — это **два rune**: `'🇺'` + `'🇦'`. Для полноценной обработки таких случаев нужны библиотеки вроде [`golang.org/x/text/unicode/norm`](https://pkg.go.dev/golang.org/x/text/unicode/norm).

---

### **Обратное преобразование: `rune` → `string`**

Любой `rune` можно превратить в строку:

```go
r := '🙂'
s := string(r)
fmt.Println(s) // → 🙂
```

Также можно собрать строку из среза `rune`:

```go
runes := []rune{'H', 'e', 'l', 'l', 'o'}
s := string(runes)
fmt.Println(s) // → Hello
```

---

### Итог: когда использовать `rune`?

| Задача | Использовать |
|-------|--------------|
| Работа с ASCII / бинарными данными | `[]byte` |
| Подсчёт, перебор, изменение **символов** | `[]rune` или `for range` |
| Обработка многоязычного текста | `rune` + пакет `unicode` |
| Эффективный перебор без копирования | `for range string` |

> ✅ Правило: если ваш текст может содержать не-ASCII символы (кириллица, эмодзи, иероглифы и т.д.) — работайте с `rune`, а не с `byte`.

Это гарантирует корректность и международную поддержку вашего кода.
### 💎 Итог

- `rune` — это `int32`, представляющий **Unicode-символ**.
- Используйте `[]rune(s)` или `for range s`, чтобы корректно работать с **многоязычным текстом**.
- Никогда не предполагайте, что `len(string)` = количество символов — это **количество байтов**.
