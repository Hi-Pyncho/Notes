### **1. Простой CLI-калькулятор**
- **Цель**: Освоить командную строку, обработку аргументов, базовую логику.
- **Функции**: Сложение, вычитание, умножение, деление. Можно добавить степень, корень.
- **Расширение**: Сохранять историю вычислений в файл.
- **Технологии**: `os.Args`, `fmt`, `strconv`.

---

### **2. Сервис для генерации коротких ссылок (URL shortener)**
- **Цель**: Понять HTTP-серверы, обработку запросов, хранение данных.
- **Функции**:
  - Принимает длинную ссылку → возвращает короткий код (например, `/abc123`).
  - При переходе по короткой ссылке — редирект на оригинал.
- **Хранение**: Используйте map в памяти (начало), затем перейдите на `sqlite3`.
- **Технологии**: `net/http`, `strings`, `sqlite3` (библиотека `mattn/go-sqlite3`).

---

### **3. Трекер ошибок (как в твоём намерении — но упрощённый)**
- **Цель**: Практика веб-сервера, JSON, логирования, взаимодействие с фронтендом.
- **Функции**:
  - REST API для приёма ошибок (POST `/api/error` с JSON: `{ message, stack, url, timestamp }`).
  - Сохраняет ошибки в файл (JSON-массив) или SQLite.
  - Веб-интерфейс (можно простой HTML + JS) для просмотра ошибок.
- **Интеграция**: Позже можно подключить Vue3 для отображения.
- **Технологии**: `net/http`, `encoding/json`, `log`, `sqlite3`.

---

### **4. Утилита для парсинга логов**
- **Цель**: Работа с файлами, регулярные выражения, обработка текста.
- **Функции**: Принимает лог-файл (например, Nginx или кастомный), считает:
  - Количество ошибок 5xx.
  - Самые частые IP-адреса.
  - Топ запрашиваемых URL.
- **Выход**: Вывод в терминал или CSV-файл.
- **Технологии**: `os`, `bufio`, `regexp`, `encoding/csv`.

---

### **5. Микросервис для хранения заметок (Notes API)**
- **Цель**: Понять REST, CRUD, структуры данных, JSON.
- **Функции**:
  - Создать заметку (POST /notes)
  - Получить все (GET /notes)
  - Получить по ID (GET /notes/{id})
  - Удалить (DELETE /notes/{id})
- **Хранение**: JSON-файл или SQLite.
- **Расширение**: Добавить авторизацию по токену (простому, например, API-ключу).
- **Технологии**: `net/http`, `encoding/json`, `path/filepath`.

---

### **6. Простой чат-сервер (TCP или WebSocket)**
- **Цель**: Работа с сокетами, многопоточность, горутины.
- **Функции**:
  - Сервер принимает подключения от клиентов.
  - Каждое сообщение от клиента рассылается всем подключённым.
  - Простой текстовый клиент (CLI) для отправки сообщений.
- **Технологии**: `net`, `goroutines`, `sync`, `bufio`.

---

### **7. Скрипт для автоматического бэкапа директорий**
- **Цель**: Работа с файловой системой, планирование, архивация.
- **Функции**:
  - Копирует содержимое заданной папки в папку `backup/`.
  - Имя бэкапа — с датой и временем (`backup_20251113_1230.zip`).
  - Удаляет бэкапы старше 7 дней.
- **Расширение**: Запуск по cron (можно сделать как системный сервис).
- **Технологии**: `os`, `filepath`, `archive/zip`, `time`.

---

### **8. Проверка доступности веб-сайтов (Ping checker)**
- **Цель**: HTTP-запросы, таймауты, параллелизм.
- **Функции**:
  - Принимает список URL из файла.
  - Проверяет доступность каждого (HTTP 200).
  - Выводит статус: `OK`, `Timeout`, `Error`.
- **Расширение**: Запуск каждые 5 минут (можно через `time.Ticker`).
- **Технологии**: `net/http`, `time`, `sync.WaitGroup`.

---

### **9. Приложение для управления задачами (To-Do CLI)**
- **Цель**: Обработка структур, работа с файлами, CLI-интерфейс.
- **Функции**:
  - Добавить задачу (`todo add "Купить молоко"`)
  - Показать список (`todo list`)
  - Отметить как выполненную (`todo done 2`)
  - Удалить (`todo delete 1`)
- **Хранение**: JSON-файл или SQLite.
- **Библиотека**: `github.com/urfave/cli/v2` — для удобного CLI.
- **Технологии**: `encoding/json`, `flag`, `os`.

---

### **10. Простой прокси-сервер**
- **Цель**: Понять HTTP-проксирование, middleware.
- **Функции**:
  - Принимает запросы на `localhost:8080`.
  - Пересылает их на другой сайт (например, `https://google.com`).
  - Логирует URL и статус ответа.
- **Расширение**: Добавить фильтрацию по домену.
- **Технологии**: `net/http/httputil`, `net/http/cookiejar`.
