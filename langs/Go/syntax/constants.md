Константы в Go — это **фиксированные значения**, которые определяются **на этапе компиляции** и **не могут быть изменены** во время выполнения программы. Они играют важную роль в повышении читаемости, безопасности и производительности кода.

---

## 🔹 1. **Объявление констант**

Используется ключевое слово `const`.

### Простое объявление:
```go
const pi = 3.14159
const appName = "MyApp"
const maxRetries = 3
```

### Групповое объявление:
```go
const (
    minPort = 1024
    maxPort = 65535
    defaultPort = 8080
)
```

### С указанием типа (редко нужно):
```go
const version string = "1.0.0"
const timeout int = 30
```

> 💡 В большинстве случаев **тип указывать не нужно** — Go выведет его автоматически.

---

## 🔸 2. **Типы значений констант**

Константы могут быть:
- **Булевыми**: `true`, `false`
- **Числовыми**: целые, вещественные, комплексные
- **Строковыми**
- **Рунами** (Unicode-символами)

Примеры:
```go
const isActive = true
const message = "Hello"
const letter = 'A'        // rune (тип int32)
const complexNum = 1 + 2i
```

> ❌ Константы **не могут быть** слайсами, мапами, структурами, функциями, указателями и т.д.  
> Только **скалярные (примитивные) типы**.

---

## 🔥 3. **Нетипизированные константы (untyped constants)**

Это одна из самых мощных особенностей Go!

Когда вы пишете:
```go
const n = 42
```
— `n` — это **нетипизированная целочисленная константа**.

### Что это даёт?
- Её можно использовать **в любом контексте**, где допустимо целое число:
  ```go
  var a int = n      // OK
  var b byte = n     // OK (если значение помещается)
  var c float64 = n  // OK
  ```
- Нет ошибок приведения типов на этапе компиляции (если значение влезает).

### Пример:
```go
const million = 1_000_000

var x int32 = million   // OK
var y float64 = million // OK
var z byte = million    // ❌ ОШИБКА: 1_000_000 не помещается в byte (0–255)
```

> ✅ Это делает константы **гибкими и безопасными**.

Если указать тип явно:
```go
const n int = 42 // теперь n — ТИПИЗИРОВАННАЯ константа
var b byte = n   // ❌ ошибка: нельзя присвоить int → byte без приведения
```

## 📏 4. **Константные выражения**

Значения констант вычисляются **на этапе компиляции** и могут быть выражениями:

```go
const (
    hoursPerDay = 24
    minutesPerDay = hoursPerDay * 60  // 1440
    secondsPerDay = minutesPerDay * 60 // 86400
)

const message = "Error: " + "file not found" // конкатенация строк
```

Допустимые операции:
- Арифметика (`+`, `-`, `*`, `/`, `%`)
- Битовые операции (`<<`, `>>`, `&`, `|`, `^`)
- Сравнения (внутри других константных выражений)
- Некоторые встроенные функции (например, `len` для строк и массивов)

Пример с `len`:
```go
const s = "hello"
const lenS = len(s) // 5 — вычисляется на этапе компиляции
```

> ❌ Нельзя вызывать обычные функции (например, `time.Now()`, `strconv.Itoa` и т.д.).

## 🧩 5. **iota — генератор констант**

`iota` — встроенная константа, которая **автоматически увеличивается** внутри блока `const`. Начинается с `0`.

### Пример: перечисления (аналог enum)
```go
const (
    Sunday = iota // 0
    Monday        // 1
    Tuesday       // 2
    Wednesday     // 3
)
```

### Пример: флаги
```go
const (
    Read   = 1 << iota // 1 (0001)
    Write              // 2 (0010)
    Execute            // 4 (0100)
    Admin              // 8 (1000)
)
```

```go
const (
  zero = 0
  one
  two
  three = iota
  four
  five
)

fmt.Println(zero, one, two, three, four, five) // 0 0 0 3 4 5

```

> 💡 `iota` сбрасывается в `0` в каждом новом блоке `const`.

---

## 🚫 6. **Что нельзя делать с константами**

- ❌ Изменять значение после объявления.
- ❌ Присваивать результат функции (кроме встроенных, разрешённых на этапе компиляции).
- ❌ Использовать переменные в выражениях констант:
  ```go
  var x = 10
  const y = x // ❌ ошибка: x — переменная, не константа
  ```

---

## ✅ 7. **Зачем использовать константы?**

- **Читаемость**: `if status == Success` лучше, чем `if status == 0`.
- **Безопасность**: компилятор гарантирует неизменяемость.
- **Производительность**: значения "вшиты" в код на этапе компиляции.
- **Поддержка**: легко менять значение в одном месте.

## 📦 Пример из стандартной библиотеки

В пакете `http`:
```go
const (
    StatusOK                   = 200
    StatusNotFound             = 404
    StatusInternalServerError  = 500
)
```

## 🔚 Заключение

Константы в Go:
- Объявляются с `const`
- Вычисляются **на этапе компиляции**
- Могут быть **нетипизированными** — это мощная фича!
- Поддерживают `iota` для автоматической нумерации
- Делают код **надёжнее, чище и быстрее**

Используйте константы вместо "магических значений" — это идиоматичный Go!
