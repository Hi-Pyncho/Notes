В Go есть **только один цикл** — это `for`. Он универсален и заменяет собой `for`, `while` и даже `do-while` из других языков. Go **не имеет** ключевых слов `while` или `do`.

---

## 🔁 1. **Три формы цикла `for`**

### ✅ Форма 1: классический `for` (с инициализацией, условием и пост-выражением)

```go
for i := 0; i < 10; i++ {
    fmt.Println(i)
}
```

Структура:
```go
for [инициализация]; [условие]; [пост-выражение] {
    // тело цикла
}
```

- `инициализация` — выполняется один раз в начале (часто объявление переменной)
- `условие` — проверяется перед каждой итерацией; если `false` — выход
- `пост-выражение` — выполняется после каждой итерации (часто инкремент)

> 💡 Все три части **необязательны**, но точки с запятой нужны, если пропускаете часть.

---

### ✅ Форма 2: `for` как `while`

Если опустить инициализацию и пост-выражение — получим аналог `while`:

```go
sum := 1
for sum < 1000 {
    sum += sum
}
```

Это эквивалентно `while (sum < 1000)` в C/Java.

Можно даже написать **бесконечный цикл**:
```go
for {
    // бесконечно
    if someCondition {
        break
    }
}
```

> 💡 `for true { ... }` — тоже работает, но `for { ... }` — идиоматичнее.

---

### ✅ Форма 3: `for range` — итерация по коллекциям

Используется для перебора элементов в:
- строках
- массивах и слайсах
- мапах
- каналах

#### Без указания индекса
```go
func RepeatWord(word string, repeat int) string {
  if (repeat == 1) {
    return word
  }

  var res string

  for range repeat {
    res += word
  }

  return res
}
```

#### 🔹 Слайсы и массивы:
```go
nums := []int{2, 4, 6}
for i, v := range nums {
    fmt.Printf("индекс: %d, значение: %d\n", i, v)
}
```

Можно игнорировать индекс или значение с помощью `_`:
```go
for _, v := range nums { ... } // только значения
for i := range nums { ... }    // только индексы
```

#### 🔹 Строки:
```go
s := "Привет"
for i, r := range s {
    fmt.Printf("байт: %d, руна: %c\n", i, r)
}
```
> ⚠️ `i` — позиция в **байтах**, `r` — **руна** (Unicode-символ).

#### 🔹 Мапы:
```go
m := map[string]int{"a": 1, "b": 2}
for key, value := range m {
    fmt.Println(key, value)
}
```
> ⚠️ Порядок итерации по мапе **случаен** (это защита от багов, зависящих от порядка).

#### 🔹 Каналы:
```go
ch := make(chan int)
go func() {
    ch <- 1
    ch <- 2
    close(ch)
}()

for v := range ch {
    fmt.Println(v) // получает 1, 2, затем выходит
}
```
Цикл завершится, когда канал **закрыт**.

## 🚦 2. **Управление циклом: `break` и `continue`**

- `break` — немедленный выход из цикла
- `continue` — переход к следующей итерации

### Метки (labels) для вложенных циклов

Если циклы вложены, можно использовать **метки**, чтобы управлять внешним циклом:

```go
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if i == 1 && j == 1 {
            break outer // выйти из внешнего цикла
            continue outer // продолжить выполение внешнего цикла
        }
        fmt.Println(i, j)
    }
}
```

Без метки `break` вышел бы только из внутреннего цикла.

---

### 🔸 Изменение элементов слайса в `range`
`range` возвращает **копии** значений, поэтому прямое изменение не работает:

```go
nums := []int{1, 2, 3}
for _, v := range nums {
    v *= 2 // ❌ не влияет на nums
}
```

✅ Чтобы изменить — используйте индекс:
```go
for i := range nums {
    nums[i] *= 2 // ✅
}
```

---

## 📌 4. **Идиомы Go с циклами**

- Бесконечный цикл: `for { ... }`
- Аналог `while`: `for условие { ... }`
- Итерация без индекса: `for _, v := range slice`
- Чтение из канала до закрытия: `for v := range ch`

---

## ✅ Заключение

Цикл `for` в Go:
- **Единственный** цикл в языке
- Очень гибкий: заменяет `for`, `while`, `foreach`
- Поддерживает `range` для безопасной итерации
- Требует внимания к деталям (особенно с указателями и замыканиями)

Используйте:
- `for i := 0; i < n; i++` — для индексов
- `for range` — для коллекций
- `for условие` — как `while`
- `for { }` — для бесконечных циклов (серверы, демоны)

Это делает Go простым, но мощным — без избыточности синтаксиса.
