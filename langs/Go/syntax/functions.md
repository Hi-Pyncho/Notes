### 1. **Объявление функции**

Синтаксис:
```go
func add(a int, b int) int {
    return a + b
}
```

- Ключевое слово `func` начинает объявление функции.
- Параметры указываются с именем и типом (`имя тип`).
- Тип возвращаемого значения указывается **после** списка параметров.
- Если функция ничего не возвращает, тип возврата **не указывается**.

Пример функции без возврата:
```go
func greet(name string) {
    fmt.Println("Hello,", name)
}
```

---

### 2. **Краткий синтаксис для одинаковых типов параметров**

Если несколько последовательных параметров имеют один и тот же тип, можно указать тип один раз в конце:

```go
func add(a, b int) int {
    return a + b
}
```
Эквивалентно `func add(a int, b int) int`.

---

### 3. **Возврат нескольких значений**

Go поддерживает возврат нескольких значений — это часто используется для возврата результата и ошибки:

```go
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}
```

Использование:
```go
result, err := divide(10, 2)
if err != nil {
    log.Fatal(err)
}
```

---

### 4. **Именованные возвращаемые значения**

Можно дать имена возвращаемым значениям. Тогда в теле функции они ведут себя как переменные, и можно использовать `return` без указания значений («naked return»):

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return // возвращает x и y
}
```

> ⚠️ Naked return допустим, но в больших функциях его лучше избегать ради читаемости.

---

### 5. **Функции как значения (first-class citizens)**

В Go функции — это значения первого класса: их можно присваивать переменным, передавать как аргументы и возвращать из других функций.

Пример:
```go
func apply(f func(int, int) int, a, b int) int {
    return f(a, b)
}

func main() {
    result := apply(add, 3, 4) // 7
}
```

Также можно объявлять анонимные функции:
```go
func main() {
    square := func(x int) int {
        return x * x
    }
    fmt.Println(square(5)) // 25
}
```

---

### 6. **Замыкания (closures)**

Функции могут «захватывать» переменные из окружающей области видимости:

```go
func counter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

func main() {
    c := counter()
    fmt.Println(c()) // 1
    fmt.Println(c()) // 2
}
```

---

### 7. **Встроенные функции**

Go предоставляет несколько встроенных функций, доступных без импорта:
- `len()`, `cap()` — длина и вместимость срезов/массивов/строк
- `make()` — создание слайсов, мапов, каналов
- `new()` — выделение памяти под тип (возвращает указатель)
- `append()`, `copy()` — работа со слайсами
- `panic()`, `recover()` — обработка паники

---

### 8. **main и init**

- `func main()` — точка входа в программу (должна быть в пакете `main`).
- `func init()` — автоматически вызывается перед `main()`. Может быть несколько `init` в одном пакете; они выполняются в порядке объявления.

### Вариатические функции

```go
func sum(nums ...int) {
    fmt.Print(nums, " ")
    total := 0

    for _, num := range nums {
        total += num
    }
    fmt.Println(total)
}

func main() {

    sum(1, 2)
    sum(1, 2, 3)

    nums := []int{1, 2, 3, 4}
    sum(nums...)
}
```

### Заключение

Функции в Go:
- Просты и строги в синтаксисе.
- Поддерживают множественный возврат.
- Могут использоваться как значения.
- Обеспечивают чистую и модульную структуру кода.

Они лежат в основе идиоматичного Go-кода, особенно в сочетании с обработкой ошибок и интерфейсами.

---

### **Имена, начинающиеся с заглавной буквы — экспортируются (публичные)**

Если имя функции **начинается с заглавной буквы** (например, `Greet`, `CalculateSum`), то эта функция **экспортируется** — то есть она **доступна из других пакетов**.

Пример:
```go
// В пакете mylib
package mylib

func PublicFunction() string {
    return "Hello from public function!"
}
```

Использование из другого пакета:
```go
package main

import "your-module/mylib"

func main() {
    msg := mylib.PublicFunction() // ✅ Работает!
    println(msg)
}
```

> 💡 Это аналог `public` в других языках (например, Java или C#).

---

### **Имена, начинающиеся со строчной буквы — не экспортируются (приватные)**

Если имя функции **начинается со строчной буквы** (например, `greet`, `calculateSum`), то она **видна только внутри своего пакета** и **недоступна извне**.

Пример:
```go
// В пакете mylib
package mylib

func privateHelper() int {
    return 42
}
```

Попытка использовать из другого пакета:
```go
package main

import "your-module/mylib"

func main() {
    x := mylib.privateHelper() // ❌ ОШИБКА КОМПИЛЯЦИИ!
}
```

> 💡 Это аналог `private` или `internal` в других языках.

---

### 📌 Важно:
- Это правило **применяется ко всем идентификаторам**: функциям, переменным, константам, типам, методам и полям структур.
- Go **не имеет** ключевых слов вроде `public`/`private` — всё решает **регистр первой буквы**.
- Имена должны быть в формате **PascalCase** (для экспорта) или **camelCase** (для внутреннего использования).

---

### Пример в одном файле:
```go
package mathutils

// Exported function — доступна извне
func Max(a, b int) int {
    return max(a, b) // вызов внутренней функции
}

// unexported (private) function — только внутри пакета
func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

---

### 💡 Советы по именованию:
- Экспортируйте **только то**, что действительно нужно другим пакетам.
- Делайте внутренние вспомогательные функции **unexported** (со строчной буквы) — это улучшает инкапсуляцию и уменьшает «поверхность API».
- Используйте понятные имена: `ParseConfig`, `validateInput`, `sendRequest` и т.д.

---

### Заключение:
> **Заглавная буква = публичный (экспортируемый)**  
> **Строчная буква = приватный (только внутри пакета)**

Это одна из ключевых идиом Go, и её понимание критически важно для написания чистого и правильно структурированного кода.
