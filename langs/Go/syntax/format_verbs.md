В Go функция `fmt.Printf` (и другие функции семейства `fmt`, такие как `Sprintf`, `Fprintf`) использует **глаголы форматирования** (format verbs) — это специальные идентификаторы вида `%...`, которые указывают, **как интерпретировать и выводить аргумент**.

## краткая таблица
Конечно! Вот удобная **таблица-шпаргалка по глаголам форматирования в `fmt.Printf`** в Go:

---

### 📋 **Шпаргалка по `fmt.Printf` в Go**

| Глагол | Тип(ы) аргумента                     | Описание |
|--------|--------------------------------------|---------|
| `%v`   | любой                                | Значение в умолчательном формате |
| `%+v`  | структуры                            | Как `%v`, но с именами полей |
| `%#v`  | любой                                | Значение в виде валидного Go-кода |
| `%T`   | любой                                | Тип значения (например, `int`, `string`, `main.Person`) |
| `%p`   | указатели                            | Адрес в шестнадцатеричном виде (`0x1234abcd`) |

---

### 🔢 **Целые числа**

| Глагол | Пример (`42`) | Описание |
|--------|---------------|---------|
| `%d`   | `42`          | Десятичная запись |
| `%b`   | `101010`      | Двоичная |
| `%o`   | `52`          | Восьмеричная |
| `%x`   | `2a`          | Шестнадцатеричная (строчные) |
| `%X`   | `2A`          | Шестнадцатеричная (заглавные) |
| `%c`   | `*`           | Символ по коду (Unicode) |
| `%U`   | `U+002A`      | Unicode-код в формате `U+XXXX` |

---

### 🧮 **Числа с плавающей точкой**

| Глагол | Пример (`123.456`) | Описание |
|--------|--------------------|---------|
| `%f`   | `123.456000`       | Десятичная запись |
| `%e`   | `1.234560e+02`     | Экспоненциальная (строчные) |
| `%E`   | `1.234560E+02`     | Экспоненциальная (заглавные) |
| `%g`   | `123.456`          | Компактный: выбирает `%e` или `%f` |
| `%G`   | `123.456`          | То же, но с заглавными буквами |

---

### 🔤 **Строки и байты**

| Глагол | Пример (`"Hi"`) | Описание |
|--------|------------------|---------|
| `%s`   | `Hi`             | Строка или `[]byte` как текст |
| `%q`   | `"Hi"`           | Строка/символ в кавычках с экранированием |
| `%x`   | `4869`           | Байты в hex (строчные) |
| `%X`   | `4869` → `4869` (но буквы заглавные, если есть) | Байты в hex (заглавные) |

> 💡 Для `[]byte`: `%s` → текст, `%x` → hex-представление.

---

### 📏 **Модификаторы ширины и точности**

| Синтаксис | Пример | Результат |
|----------|--------|----------|
| `%5d`    | `fmt.Printf("%5d", 7)`     | `    7` (5 позиций, выравнивание по правому краю) |
| `%-5d`   | `fmt.Printf("%-5d", 7)`    | `7    ` (выравнивание по левому краю) |
| `%05d`   | `fmt.Printf("%05d", 7)`    | `00007` |
| `%.2f`   | `fmt.Printf("%.2f", 3.1415)` | `3.14` |
| `%8.2f`  | `fmt.Printf("%8.2f", 3.1415)`| `    3.14` (всего 8 символов, из них 2 после точки) |

---

### ✅ **Рекомендации**
- Для отладки: используй `%#v` и `%T`.
- Для обычного вывода: `%v`.
- Для чисел: `%d` (целые), `%f` или `%g` (дробные).
- Для строк: `%s` или `%q` (если нужно экранирование).

## Подробнее
---

### 🔢 **Для чисел**

| Глагол | Описание |
|--------|---------|
| `%v`   | Значение в **умолчательном формате** (универсальный) |
| `%+v`  | Как `%v`, но для структур выводит **имена полей** |
| `%#v`  | Go-синтаксис: выводит значение так, что его можно **скопировать как код** |
| `%d`   | **Целое число** в десятичной системе (`int`, `int32`, `uint` и т.д.) |
| `%b`   | Целое в **двоичной** системе |
| `%o`   | Целое в **восьмеричной** системе |
| `%x`   | Целое в **шестнадцатеричной** (строчные буквы: `a–f`) |
| `%X`   | Целое в **шестнадцатеричной** (заглавные буквы: `A–F`) |
| `%c`   | Символ Unicode по коду (например, `65` → `'A'`) |
| `%U`   | Unicode-код в формате `U+1234` |

> Пример:  
> ```go
> fmt.Printf("%d", 42)    // 42  
> fmt.Printf("%b", 5)     // 101  
> fmt.Printf("%x", 255)   // ff  
> fmt.Printf("%U", 'я')   // U+044F  
> ```

---

### 🧮 **Для чисел с плавающей точкой**

| Глагол | Описание |
|--------|---------|
| `%f`   | Десятичная запись (`123.456`) |
| `%e`   | Экспоненциальная форма, строчные (`1.234e+02`) |
| `%E`   | Экспоненциальная форма, заглавные (`1.234E+02`) |
| `%g`   | Компактный: выбирает `%e` или `%f` в зависимости от величины |
| `%G`   | То же, что `%G`, но с заглавными буквами |

> Пример:  
> ```go
> fmt.Printf("%f", 123.456)  // 123.456000  
> fmt.Printf("%e", 123.456)  // 1.234560e+02  
> fmt.Printf("%g", 123.456)  // 123.456  
> ```

---

### 🔤 **Для строк и байтов**

| Глагол | Описание |
|--------|---------|
| `%s`   | Строка (`string`) или срез байт (`[]byte`) как текст |
| `%q`   | Строка или символ в **кавычках**, с экранированием (как в коде) |
| `%x`   | Содержимое `[]byte` или `string` в **hex** (по байтам) |
| `%X`   | То же, но заглавные hex-буквы |

> Пример:  
> ```go
> fmt.Printf("%s", "hello")     // hello  
> fmt.Printf("%q", "hello")     // "hello"  
> fmt.Printf("%x", "AB")        // 4142  
> fmt.Printf("%q", 'A')         // 'A'  
> ```

---

### 🧱 **Для структур, указателей, интерфейсов**

| Глагол | Описание |
|--------|---------|
| `%v`   | Универсальный вывод (рекомендуется по умолчанию) |
| `%+v`  | Для структур — с именами полей |
| `%#v`  | Вывод в виде **валидного Go-кода** |
| `%p`   | Адрес указателя в шестнадцатеричном виде (`0x...`) |
| `%T`   | **Тип** значения (очень полезен для отладки!) |

> Пример:  
> ```go
> type Person struct { Name string }
> p := Person{"Alice"}
> fmt.Printf("%v", p)    // {Alice}
> fmt.Printf("%+v", p)   // {Name:Alice}
> fmt.Printf("%#v", p)   // main.Person{Name:"Alice"}
> fmt.Printf("%T", p)    // main.Person
> fmt.Printf("%p", &p)   // 0xc000010230
> ```

---

### 📏 **Модификаторы ширины и точности**

Можно управлять **шириной поля** и **количеством знаков после запятой**:

- `%5d` — минимум 5 символов, дополняет пробелами слева.
- `%-5d` — выравнивание по левому краю.
- `%05d` — дополняет нулями.
- `%.2f` — 2 знака после запятой.
- `%8.2f` — ширина 8, из них 2 после точки.

> Пример:  
> ```go
> fmt.Printf("%04d", 7)   // 0007  
> fmt.Printf("%.2f", 3.14159) // 3.14  
> ```

---

### 💡 Советы
- **`%v` — твой друг по умолчанию**. Используй его, если не нужен специфичный формат.
- **`%T` — незаменим при отладке типов** (особенно с `interface{}`).
- **`%#v` — помогает увидеть, как значение выглядит в исходном коде**.
