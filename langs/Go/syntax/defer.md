Конструкция `defer` в Go используется для **откладывания выполнения** функции до тех пор, пока окружающая (обрамляющая) функция не завершится. Это удобный и надежный способ гарантировать выполнение важных действий, таких как освобождение ресурсов, закрытие файлов или соединений, сброс мьютексов и т.д.

### Синтаксис

```go
defer выражение
```

`выражение` — это вызов функции (обычно), который будет отложен до завершения текущей функции.

### Как работает `defer`

- `defer` регистрирует вызов функции в стеке отложенных вызовов.
- Все отложенные вызовы выполняются в **обратном порядке** (LIFO — Last In, First Out), когда окружающая функция завершается (независимо от того, завершилась ли она нормально или через `panic`).
- Аргументы функции, указанной в `defer`, вычисляются **в момент регистрации** `defer`, а не в момент выполнения.

### Примеры

#### 1. Простой пример

```go
package main

import "fmt"

func main() {
    fmt.Println("1")
    defer fmt.Println("deferred 2")
    fmt.Println("3")
    // Вывод:
    // 1
    // 3
    // deferred 2
}
```

#### 2. Множественные `defer`

```go
func main() {
    defer fmt.Println("first deferred")
    defer fmt.Println("second deferred")
    defer fmt.Println("third deferred")
    fmt.Println("main function end")
    // Вывод:
    // main function end
    // third deferred
    // second deferred
    // first deferred
}
```

#### 3. Использование `defer` для закрытия файла

```go
package main

import (
    "fmt"
    "os"
)

func readFile(filename string) {
    file, err := os.Open(filename)
    if err != nil {
        panic(err)
    }
    defer file.Close() // Гарантированное закрытие файла

    // Работа с файлом...
    fmt.Println(file.Name(), "is open")
}
```

#### 4. Аргументы вычисляются при вызове `defer`

```go
func main() {
    i := 0
    defer fmt.Println(i) // Будет напечатано 0
    i++
    return
    // Вывод: 0
}
```

#### 5. `defer` и возвращаемые значения

Если `defer` изменяет именованные возвращаемые значения, это влияет на результат функции:

```go
func f() (result int) {
    defer func() {
        result++
    }()
    return 0
}
// f() вернет 1, а не 0
```

### Когда использовать `defer`

- **Закрытие ресурсов**: файлов, сетевых соединений, баз данных.
- **Сброс мьютексов** (`mutex.Unlock()`).
- **Логирование** времени выполнения функции.
- **Восстановление после паники** (`recover` внутри `defer`).

### Полезные особенности

- `defer` может быть вызван изнутри цикла или условия — каждый вызов будет зарегистрирован.
- `defer` работает даже если функция завершается через `return`, `panic` или обычное завершение.

### Резюме

- `defer` откладывает выполнение функции до завершения текущей функции.
- Отложенные вызовы выполняются в обратном порядке (LIFO).
- Аргументы функции в `defer` вычисляются при регистрации, а не при выполнении.
- `defer` особенно полезен для управления ресурсами и гарантии выполнения очистки.
