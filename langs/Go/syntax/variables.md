В языке Go переменные — это именованные области памяти, используемые для хранения данных. Они имеют **тип**, **имя**, **значение** и **область видимости**. Go — статически типизированный язык, поэтому тип переменной определяется **на этапе компиляции** и не может меняться в ходе выполнения программы.

---

## Основные характеристики переменных в Go

### 1. **Объявление переменных**

Go предоставляет несколько способов объявления переменных:

#### a) Полная форма с ключевым словом `var`:
```go
var name string
var age int = 25
var height = 175.5 // тип выводится автоматически (float64)
```

- Если значение не указано, переменная инициализируется **нулевым значением** своего типа:
  - `0` для чисел,
  - `""` для строк,
  - `false` для `bool`,
  - `nil` для указателей, срезов, мап, каналов и т.д.

#### b) Краткая форма (только внутри функций!):
```go
name := "Alice"
age := 30
```
- Оператор `:=` **объявляет и инициализирует** переменную одновременно.
- Тип выводится из правой части.
- **Нельзя использовать вне функций** (например, на уровне пакета).

> ⚠️ `:=` можно использовать только при **первом объявлении** переменной. Повторное присваивание требует `=`.

---

### 2. **Типы переменных**

Go имеет встроенные типы:
- **Числовые**: `int`, `int8`, `int16`, `int32`, `int64`, `uint`, `float32`, `float64`, `complex64`, `complex128`
- **Логический**: `bool`
- **Строковый**: `string`
- **Составные**: массивы, срезы (`[]T`), мапы (`map[K]V`), структуры (`struct`), указатели (`*T`), функции, интерфейсы и др.

Пример:
```go
var scores []int          // срез целых чисел
var person map[string]int // мапа: строка → целое
```

---

### 3. **Область видимости (scope)**

- **Локальные переменные**: объявлены внутри функции или блока `{}` — видны только внутри этого блока.
- **Пакетные переменные**: объявлены вне функций — видны во всём пакете.
  - Если имя **начинается с заглавной буквы** (`MyVar`) — переменная **экспортируется** (доступна из других пакетов).
  - Если с маленькой (`myVar`) — **приватная** для пакета.

Пример:
```go
package main

var PublicVar = "I'm visible outside"
var privateVar = "I'm only for this package"

func main() {
    localVar := "only here"
}
```

---

### 4. **Нулевые значения (zero values)**

Если переменная объявлена, но не инициализирована, Go присваивает ей **нулевое значение**:
```go
var a int     // 0
var b string  // ""
var c bool    // false
var d *int    // nil
var e []int   // nil (но len=0, cap=0 после make)
```

---

### 5. **Множественное объявление**

Go позволяет объявлять несколько переменных сразу:
```go
var x, y, z int = 1, 2, 3
name, age := "Bob", 28
```

Также можно группировать объявления на уровне пакета:
```go
var (
    host = "localhost"
    port = 8080
    debug = true
)
```

---

### 6. **Переменные и память**

- Go управляет памятью автоматически (сборка мусора).
- Переменные могут размещаться в **стеке** (для локальных, короткоживущих) или в **куче** (если требуется долгоживущий доступ, например, через указатель).
- Указатели позволяют работать с адресами памяти:
  ```go
  x := 42
  p := &x    // p — указатель на x
  fmt.Println(*p) // 42
  ```

---

### 7. **Константы vs переменные**

- `const` — неизменяемые значения, определяются на этапе компиляции.
- `var` — изменяемые переменные.

```go
const Pi = 3.14159
var radius = 5.0
```

---

## Практические советы

- Используйте `:=` внутри функций — это идиоматично.
- Избегайте глобальных переменных без необходимости.
- Имена экспортируемых переменных пишите с **заглавной буквы**.
- Не объявляйте переменные без необходимости — Go поощряет минимализм.

---

## Пример полной программы

```go
package main

import "fmt"

var globalCounter = 0 // пакетная переменная

func main() {
    message := "Hello, Go!"
    count := 3

    for i := 0; i < count; i++ {
        fmt.Println(message, i)
        globalCounter++
    }

    fmt.Println("Global counter:", globalCounter)
}
```
