
| Команда              | Назначение                                                                                                 | Пример использования                                                                 |
| :------------------- | :--------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------- |
| `go build`           | Компилирует пакеты и зависимости.                                                                     | `go build main.go` - компилирует файл `main.go` в исполняемый файл.                  |
| `go clean`           | Удаляет файлы, созданные предыдущими командами.                                                       | `go clean -cache` - удаляет содержимое кэша сборки.                                  |
| `go doc`             | Показывает документацию к пакету или символу.                                                              | `go doc fmt.Printf` - показывает документацию для функции `fmt.Printf`.              |
| `go env`             | Печатает или изменяет переменные окружения Go.                                                             | `go env GOPATH` - выводит текущее значение переменной `GOPATH`.                      |
| `go get`             | Скачивает и устанавливает пакеты и зависимости.                                                       | `go get github.com/user/repo` - скачивает и устанавливает пакет из репозитория.      |
| `go install`         | Компилирует и устанавливает пакеты и зависимости.                                                     | `go install mypackage` - компилирует и устанавливает `mypackage` в `GOPATH/bin`.     |
| `go list`            | Выводит список пакетов или модулей.                                                                        | `go list ./...` - выводит список всех пакетов в текущей директории и поддиректориях. |
| `go mod`             | Управляет модулями Go.                                                                                     | `go mod init mymodule` - инициализирует новый модуль.                                |
| `go run`             | Компилирует и запускает программу Go.                                                                 | `go run main.go` - компилирует и запускает файл `main.go`.                           |
| `go test`             | Запускает тесты.                                                                                      | `go test ./...` - запускает все тесты в текущей директории и поддиректориях.         |
| `go tool`            | Запускает вспомогательные инструменты Go.                                                            | `go tool objdump mybinary` - дампит объектный код исполняемого файла.                |
| `go version`         | Печатает версию Go.                                                                                        | `go version` - выводит установленную версию Go.                                      |
| `go vet`             | Сообщает о возможных ошибках в пакетах.                                                                    | `go vet mypackage` - проверяет пакет `mypackage` на наличие потенциальных ошибок.    |
