| Команда | Сокращение | Описание |
|--------|------------|----------|
| `help` | `h` | Показать список всех команд |
| `continue` | `c` | Продолжить выполнение до следующей точки останова |
| `next` | `n` | Выполнить следующую строку (не заходить внутрь функций) |
| `step` | `s` | Зайти внутрь функции (шагнуть внутрь) |
| `stepout` | `so` | Выйти из текущей функции |
| `break <func>` | `b <func>` | Установить точку останова на функции |
| `break main.go:10` | `b main.go:10` | Установить точку останова на строке 10 |
| `breakpoints` | `bp` | Показать все точки останова |
| `clear <id>` | — | Удалить точку останова по ID |
| `clearall` | — | Удалить все точки останова |
| `print <var>` | `p <var>` | Вывести значение переменной |
| `whatis <var>` | — | Показать тип переменной |
| `locals` | — | Показать все локальные переменные |
| `args` | — | Показать аргументы функции |
| `list` | `l` | Показать текущий участок кода |
| `list <func>` | — | Показать весь код функции |
| `stack` | `bt` | Показать стек вызовов |
| `frame <n>` | — | Перейти к фрейму N в стеке |
| `goroutines` | — | Показать список всех горутин |
| `goroutine <id>` | — | Переключиться на горутину с ID |
| `source <file>` | — | Выполнить команды из файла |
| `restart` | `r` | Перезапустить программу |
| `exit` / `quit` | `q` | Выйти из отладчика |

---

### 📌 Примеры использования

| Задача | Команда |
|-------|---------|
| Установить точку останова на `main` | `b main.main` |
| Установить точку на строке 15 | `b main.go:15` |
| Вывести значение `input` | `print input` |
| Показать локальные переменные | `locals` |
| Продолжить выполнение | `c` |
| Выполнить следующую строку | `n` |
| Зайти внутрь функции | `s` |
| Показать стек вызовов | `bt` |
| Перейти к фрейму 2 | `frame 2` |
| Выйти из отладчика | `quit` |

### 🧪 Полезные команды при работе с горутинами

| Команда | Описание |
|--------|----------|
| `goroutines` | Показать все активные горутины |
| `goroutine 1` | Переключиться на горутину с ID 1 |
| `goroutine <id> bt` | Показать стек вызовов для горутины ID |

### 🧩 Отладка бинарника или тестов

| Задача | Команда |
|-------|---------|
| Запустить отладку бинарника | `dlv exec ./mybinary` |
| Запустить отладку тестов | `dlv test` |
| Подключиться к процессу | `dlv attach PID` |

---

### 💡 Примечания

- Все команды можно сокращать до первых букв, если это не вызывает конфликта (например, `n` вместо `next`, `c` вместо `continue`).
- `dlv` **автоматически** компилирует с нужными флагами (`-gcflags="all=-N -l"`), если запускается через `dlv debug main.go`.
- `dlv` **работает с модулями**, `go.mod`, зависимостями — всё разрешается автоматически.
