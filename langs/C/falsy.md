В языке **C** (в отличие от C++, Java, Python и других) **нет встроенного логического типа `bool`** в классическом смысле (до стандарта C99). Однако в **C99** был добавлен тип `_Bool`, а с заголовком `<stdbool.h>` — удобный псевдоним `bool`, а также константы `true` и `false`.

Но самое главное: **в условных выражениях (в `if`, `while`, `for` и т.д.) любое скалярное значение приводится к «истинности» по простому правилу**:

> **Ноль — ложь (`false`), всё остальное — истина (`true`).**

Это правило применяется **ко всем арифметическим типам и указателям**.

---

### Как работает приведение к "булеву" значению в C:

#### 1. **Целые и вещественные числа**
- `0`, `0.0`, `-0.0` → **ложь**
- Любое ненулевое число (`1`, `-5`, `3.14`, `-0.001`) → **истина**

```c
if (0)        // false
if (1)        // true
if (-42)      // true
if (0.0)      // false
if (0.0001)   // true
```

#### 2. **Указатели**
- `NULL` (или `0`, или `(void*)0`) → **ложь**
- Любой **ненулевой адрес** → **истина**

> ⚠️ Важно: даже если указатель «некорректный» (например, висячий или неинициализированный), но не равен `NULL`, он считается **истинным**!

```c
if (NULL)     // false
int x = 5;
if (&x)       // true — адрес переменной
```

#### 3. **Строки (массивы символов / `char*`)**
- Строка `""` — это **не нулевой указатель**, а указатель на массив, где первый символ — `'\0'`.
- Поэтому `""` — это **ненулевой адрес**, и условие будет **истинным**!

```c
if ("")       // true! Потому что "" — это адрес строки в памяти (не NULL)
if ("hello")  // true
if (NULL)     // false
```

✅ Правильно проверять пустую строку так:
```c
char *s = "";
if (s != NULL && s[0] != '\0') {
    // строка не NULL и не пустая
}
```

#### 4. **Массивы (в контексте указателей)**
Если передать массив в условие (например, как указатель), он **декэйится в адрес первого элемента**, который почти всегда ненулевой:

```c
char buf[10];
if (buf)      // true — buf — адрес начала массива (не NULL)
```

### Примеры:

| Выражение         | Результат в `if` | Почему |
|------------------|------------------|--------|
| `if (0)`         | ❌ false         | ноль |
| `if (1)`         | ✅ true          | ненулевое число |
| `if (-1)`        | ✅ true          | ненулевое |
| `if (0.0)`       | ❌ false         | ноль |
| `if (NULL)`      | ❌ false         | нулевой указатель |
| `if ("")`        | ✅ true          | адрес строки ≠ NULL |
| `if ("abc")`     | ✅ true          | адрес ≠ NULL |
| `if ((void*)0)`  | ❌ false         | явный нулевой указатель |

### Стандарт C99 и `bool`

С `<stdbool.h>` можно писать более читаемо:
```c
#include <stdbool.h>

bool flag = (x != 0); // явное приведение
if (flag) { ... }
```

Но **внутри `if` всё равно действует то же правило**: `flag` — это на самом деле `_Bool`, который хранит либо `0`, либо `1`.

---

### ⚠️ Распространённая ошибка

**Нельзя проверять пустую строку как `if (!str)`** — это проверяет, не `NULL` ли указатель, а **не пустая ли строка**!

```c
char *s = "";
if (!s) {
    // ❌ Этот блок НЕ выполнится, потому что s != NULL
}
```

Чтобы проверить, пустая ли строка:
```c
if (s == NULL || s[0] == '\0') {
    // строка либо не существует, либо пустая
}
```

---

### Вывод

В C **«булево» значение — это просто правило интерпретации**:
> **0 → ложь, всё остальное → истина**  
> (для чисел — ноль, для указателей — `NULL`)

Это простое, но мощное правило лежит в основе всей логики условий в C.
