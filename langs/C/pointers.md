# Pointers

a pointer is just a variable that stores a memory address

```c
int age = 37;
int *pointerToThing;
int *agePointer = &age;

printf("The address of age is: %p\n", agePointer); // 0xff0f0df...
printf("The address of thing is: %p\n", pointerToThing); // nil
printf("The value of age is: %d\n", *agePointer); // 37

*agePointer = 42; // change value

printf("The value of age is: %d\n", *agePointer); // 42
return 0;

```

## арифметика указателей
Арифметика указателей — это возможность выполнять математические операции (сложение, вычитание, инкремент, декремент) над указателями для перемещения по памяти. Это одна из ключевых особенностей языка C, позволяющая эффективно работать с массивами, строками и динамическими структурами данных.

```c
int arr[3] = {10, 20, 30};
int *ptr = arr;  // ptr указывает на arr[0]

ptr++;  // Теперь ptr указывает на arr[1] (адрес увеличился на sizeof(int))
printf("%d", *ptr); // 20

int *ptr2 = arr + 2;  // ptr2 указывает на arr[2]
printf("%d", *ptr2);  // 30

ptr2 -= 1;  // Теперь ptr2 указывает на arr[1]
printf("%d", *ptr2);  // 20

int *ptr1 = &arr[0];
int *ptr2 = &arr[2];
printf("%ld", ptr2 - ptr1);  // 2 (элемента)
```

Указатели перемещаются не на 1 байт, а на размер типа:

`char*` → шаг 1 байт (sizeof(char) = 1).

`int*` → шаг 4 байта (если sizeof(int) = 4).

`double*` → шаг 8 байт (если sizeof(double) = 8).

Итерация по массивам без индексов
```c
int arr[5] = {1, 2, 3, 4, 5};
for (int *p = arr; p < arr + 5; p++) {
  printf("%d ", *p);  // 1 2 3 4 5
}
```

Доступ к элементам структур
```c
struct Point { int x; int y; } points[3];
struct Point *ptr = points;
ptr->x = 10;  // points[0].x = 10
(ptr + 1)->y = 20;  // points[1].y = 20
```

Пример: Поиск длины строки
```c
size_t strlen(const char *s) {
  const char *p = s;
  while (*p != '\0') p++;
  return p - s;  // Разница между указателями = длина строки
}
```

## разница элементов и байт

```c
int diff = &numbers[4] - &numbers[0]; // количество элементов
long offset = (char *)&numbers[4] - (char *)&numbers[0]; // количество байт
long offset2 = diff * sizeof(int); // количество байт

printf("%zu\n", offset); // 16
printf("%zu\n", offset2); // 16
printf("%d\n", diff); // 4
```

## pointer to pointer

| Выражение | Тип | Описание |
|----------|-----|---------|
| `int a` | `int` | Переменная |
| `int *p` | `int*` | Указатель на `int` |
| `int **pp` | `int**` | Указатель на указатель на `int` |

То есть:
`pp` → хранит адрес переменной типа `int*`  
а `int*` → хранит адрес переменной типа `int`

---

### Визуализация

```c
int a = 42;
int *p = &a;     // p — указатель на a
int **pp = &p;   // pp — указатель на p
```

Память:

```
+--------+     +--------+     +--------+
|  pp    | --> |   p    | --> |   a    |
| &p     |     | &a     |     |  42    |
+--------+     +--------+     +--------+
 int**          int*           int
```

---

### Как разыменовывать?

| Выражение | Что делает |
|----------|------------|
| `pp`     | Адрес указателя `p` |
| `*pp`    | Значение `p` → адрес `a` (`&a`) |
| `**pp`   | Значение `a` → `42` |

Пример:
```c
printf("%d\n", **pp); // Выведет 42
```

---

### Зачем нужен указатель на указатель?

#### ✅ 1. **Изменение указателя внутри функции**

В C всё передаётся **по значению**. Если ты передаёшь указатель в функцию — копируется **сам указатель**, а не то, на что он указывает.

Чтобы **изменить сам указатель**, нужно передать **указатель на него**.

##### Пример: выделение памяти в функции

```c
#include <stdio.h>
#include <stdlib.h>

void create_array(int **ptr, int size) {
  *ptr = malloc(size * sizeof(int));  // меняем значение по адресу ptr
  if (*ptr) {
    for (int i = 0; i < size; i++) {
      (*ptr)[i] = i * i;
    }
  }
}

int main() {
  int *arr = NULL;
  create_array(&arr, 5);  // передаём адрес указателя

  if (arr) {
    for (int i = 0; i < 5; i++) {
      printf("%d ", arr[i]);  // 0 1 4 9 16
    }
    free(arr);
  }
  return 0;
}
```

📌 Без `int**` нельзя было бы изменить `arr` внутри функции.

---

#### ✅ 2. **Двумерные массивы (динамические)**

Часто используется для создания **массива массивов** — например, матрицы.

```c
int rows = 3, cols = 4;
int **matrix = malloc(rows * sizeof(int*));

for (int i = 0; i < rows; i++) {
  matrix[i] = malloc(cols * sizeof(int));
  for (int j = 0; j < cols; j++) {
    matrix[i][j] = i * cols + j;
  }
}
```

Теперь можно использовать:
```c
printf("%d\n", matrix[1][2]); // элемент строки 1, столбца 2
```

Освобождение:
```c
for (int i = 0; i < rows; i++) {
  free(matrix[i]);
}
free(matrix);
```

---

#### ✅ 3. **Массив указателей на строки**

```c
char **words = malloc(3 * sizeof(char*));
words[0] = "Hello";
words[1] = "World";
words[2] = "C";

for (int i = 0; i < 3; i++) {
  printf("%s\n", words[i]);
}
free(words);
```

Используется, например, в `argv`:

```c
int main(int argc, char **argv) {
  for (int i = 0; i < argc; i++) {
    printf("arg %d: %s\n", i, argv[i]);
  }
  return 0;
}
```

`argv` — это **массив строк**, то есть `char **`.

---

#### ✅ 4. **Списки указателей, деревья, сложные структуры**

Например, дерево:
```c
struct Node {
  int data;
  struct Node **children;
  int child_count;
};
```

---

### Чем `int **ptr` отличается от `int *ptr[]`?

| Выражение | Тип | Контекст |
|----------|-----|---------|
| `int **ptr` | Указатель на указатель | Динамическая память, передача в функцию |
| `int *ptr[]` | Массив указателей | Статический размер (на этапе компиляции) |

Пример:
```c
int *arr[10];   // массив из 10 указателей на int
int **ptr;      // указатель на указатель — может указывать на динамический массив указателей
```

`int **ptr` — более гибкий, используется для динамики.

---

### Распространённые ошибки

#### ❌ Не выделил память
```c
int **pp;
**pp = 5; // ❌ Ошибка! pp и *pp — мусор
```

#### ❌ Забыл освободить
```c
int **matrix = malloc(...);
// ... забыл free(matrix[i]) и free(matrix)
// → утечка памяти
```

#### ❌ Двойное освобождение
```c
free(*pp);
free(*pp); // ❌ UB
```

---

### Вывод

| Когда использовать `int **ptr`? | Пример |
|-------------------------------|--------|
| Нужно изменить указатель в функции | `void func(int **ptr)` |
| Динамический 2D массив | `int **matrix = malloc(...)` |
| Массив строк | `char **words` |
| Работа с `argv` | `int main(int argc, char **argv)` |

---

💡 **Правило большого пальца**:
> Если тебе нужно **изменить указатель**, передавай **указатель на него** (`&ptr`) → принимающая функция должна принимать `T**`.

## void pointers

`void*` — это **указатель на "ничто" (пустой указатель)**.  
Он может указывать на **область памяти любого типа**, но **не знает, какой именно тип там лежит**.

### Пример:
```c
int x = 10;
double y = 3.14;
char str[] = "Hello";

void *ptr;

ptr = &x;    // OK: указывает на int
ptr = &y;    // OK: указывает на double
ptr = str;   // OK: указывает на char[]
```

✅ `void*` может хранить адрес любого объекта.

---

### Почему `void*` полезен?

#### 1. **Универсальность**
`void*` используется, когда ты **ещё не знаешь**, на что именно указатель будет ссылаться, или когда нужно **передать данные "общего" типа**.

#### 2. **Интерфейс для библиотечных функций**
Многие стандартные функции C используют `void*`, например:

- `malloc`: возвращает `void*`, потому что выделенная память — "сырая", без типа.
  ```c
  int *arr = malloc(10 * sizeof(int)); // malloc возвращает void*
  ```
  (В C не нужно явно приводить `void*` к другому типу, но можно.)

- `qsort`, `bsearch` — принимают `void*` для сравнения любых типов:
  ```c
  void qsort(void *base, size_t nmemb, size_t size,
             int (*compar)(const void *, const void *));
  ```

---

### Ограничения `void*`

#### ❌ Нельзя разыменовывать напрямую:
```c
int x = 42;
void *ptr = &x;

// ОШИБКА:
// printf("%d\n", *ptr); // Нельзя: *ptr — типа void, а void — неполный тип
```

> ❗ Ошибка компиляции: **invalid use of void expression**

#### ✅ Нужно привести к конкретному типу:
```c
printf("%d\n", *(int*)ptr); // OK: привели void* к int*, потом разыменовали
```

---

### Приведение типов (casting)

Ты **должен вручную привести** `void*` к нужному типу указателя:

```c
double pi = 3.1415;
void *ptr = &pi;

double value = *(double*)ptr;  // Привели и разыменовали
printf("%.4f\n", value);       // 3.1415
```

---

### Выравнивание и безопасность

- `void*` гарантирует, что может хранить адрес **любого объекта** в системе.
- Он обычно имеет **такой же размер**, как и другие указатели (например, 8 байт на 64-битной системе).
- Совместим с любым типом указателя **без явного приведения** (в C).

> ⚠️ В C++ уже нужно явное приведение: `(int*)ptr`, а в C — можно без.

---

### Пример: универсальная структура

```c
typedef struct {
  void *data;
  size_t size;        // размер данных в байтах
  char type[10];      // например, "int", "double", "string"
} generic_t;

// Пример использования:
int a = 42;
double b = 3.14;
char *s = "hello";

generic_t g1 = { .data = &a, .size = sizeof(int), .type = "int" };
generic_t g2 = { .data = &b, .size = sizeof(double), .type = "double" };
generic_t g3 = { .data = s, .size = strlen(s) + 1, .type = "string" };

// При использовании — приводим обратно:
printf("int: %d\n", *(int*)g1.data);
printf("double: %.2f\n", *(double*)g2.data);
printf("string: %s\n", (char*)g3.data); // здесь не нужно *, т.к. char* и так указатель
```

---

### Распространённые случаи использования `void*`

| Случай | Описание |
|-------|--------|
| `malloc`, `calloc`, `realloc` | Возвращают `void*` — "сырая" память |
| `qsort`, `bsearch` | Работают с любыми типами через `void*` |
| Коллекции / контейнеры | Реализация "универсальных" списков, массивов |
| Callback-функции | Передача данных через `void*` (например, в потоках) |
| ООП-подобные структуры в C | Например, в библиотеках вроде GLib |

---

### ⚠️ Опасности

1. **Нет типобезопасности**
   - Можно случайно привести `void*` не к тому типу → **неопределённое поведение**.
```c
int x = 100;
void *ptr = &x;
printf("%f\n", *(double*)ptr); // БУГ! интерпретируем int как double
 ```

2. **Нет контроля размера**
   - `void*` не хранит информацию о размере данных — только ты должен помнить.

3. **Утечки памяти**
   - Если `void*` указывает на `malloc`, забудешь `free` — будет утечка.

---

### Полезный совет: `void*` и `memcpy`

Когда работаешь с `void*`, часто используется `memcpy` для копирования данных:

```c
void *dest = malloc(sizeof(int));
int src = 42;
memcpy(dest, &src, sizeof(int)); // копируем значение через void*
```
