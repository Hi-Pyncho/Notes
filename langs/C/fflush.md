Функция `fflush` в языке C определена в стандартной библиотеке `<stdio.h>` и используется для **принудительной синхронизации буфера потока с устройством или файлом**, с которым этот поток связан.

---

### Синтаксис

```c
int fflush(FILE *stream);
```

- Если `stream` — указатель на **выходной** (`output`) или **обновляемый** (`update`, т.е. открытый с флагами `"r+"`, `"w+"` и т.п.) поток, то `fflush` записывает всё содержимое буфера этого потока в соответствующий файл или устройство (например, терминал).
- Если передать `NULL` в качестве аргумента, `fflush` сбросит буферы **всех выходных потоков**.
- Для **входных** (`input`) потоков (например, `stdin`) поведение функции `fflush` **не определено стандартом C**. На практике использование `fflush(stdin)` — распространённая, но **непереносимая и потенциально ошибочная** практика .

---

### Зачем это нужно?

Стандартные потоки ввода-вывода в C обычно **буферизованы**. Это означает, что данные не отправляются сразу на устройство (например, в терминал), а накапливаются в буфере до тех пор, пока:
- буфер не заполнится,
- не будет выведен символ новой строки (`\n`) — для **строчно-буферизованных** потоков, таких как `stdout` при выводе в терминал,
- или не будет вызвана функция `fflush`.

Пример:

```c
#include <stdio.h>

int main() {
    printf("Введите ваше имя: ");  // нет \n в конце
    fflush(stdout);                // гарантируем немедленный вывод
    char name[50];
    fgets(name, sizeof(name), stdin);
    return 0;
}
```

Без `fflush(stdout)` приглашение может не появиться на экране до тех пор, пока пользователь не введёт данные, потому что `stdout` буферизован и ждёт `\n` или заполнения буфера .

---

### Важные моменты:

- `fflush` **работает только с выходными потоками**. Попытка использовать его для очистки входного буфера (`stdin`) — **неопределённое поведение по стандарту C**, хотя некоторые компиляторы (например, MSVC) могут поддерживать это как расширение .
- Возвращает `0` при успехе и `EOF` при ошибке.
- Особенно полезна при работе с интерактивными программами, логированием в реальном времени или при отладке .

---

### Пример с файлом:

```c
FILE *fp = fopen("log.txt", "w");
fprintf(fp, "Событие произошло");
fflush(fp); // данные гарантированно записаны на диск сейчас
// ... продолжение работы
fclose(fp);
```

Это может быть важно, если программа может аварийно завершиться — без `fflush` последние сообщения могут остаться в буфере и не попасть в файл.

```c
printf(".");
fflush(stdout);
printf(".");
fflush(stdout);
// ..

printf(".\n");
printf(".\n");
/*
  .
  .
*/
```

---

### Итог

`fflush(stream)` — это способ **принудительно сбросить буфер вывода** в связанное устройство или файл. Это критически важно для обеспечения своевременного отображения или сохранения данных, особенно в интерактивных приложениях .
