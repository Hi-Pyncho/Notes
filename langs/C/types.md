## Основные встроенные типы в C

| Тип | Минимальный размер | Типичный размер (на 32/64-битных системах) | Диапазон (пример) |
|-----|--------------------|-------------------------------------------|-------------------|
| `char` | 1 байт (8 бит) | 1 байт | -128 … 127 или 0 … 255 (зависит от signedness) |
| `signed char` | 1 байт | 1 байт | -128 … 127 |
| `unsigned char` | 1 байт | 1 байт | 0 … 255 |
| `short` / `short int` | 16 бит (2 байта) | 2 байта | -32,768 … 32,767 |
| `unsigned short` | 16 бит | 2 байта | 0 … 65,535 |
| `int` | 16 бит | 4 байта (32 бита) | -2,147,483,648 … 2,147,483,647 |
| `unsigned int` | 16 бит | 4 байта | 0 … 4,294,967,295 |
| `long` | 32 бита | 4 байта (32 бита) на Windows, 8 байт (64 бита) на Linux/macOS (64-bit) | зависит от ОС |
| `unsigned long` | 32 бита | 4 или 8 байт |
| `long long` (C99) | 64 бита | 8 байт | ±9,223,372,036,854,775,807 |
| `unsigned long long` | 64 бита | 8 байт | до 18 квинтиллионов |
| `float` | 32 бита | 4 байта | ~±3.4e38 (7 знаков точности) |
| `double` | 64 бита | 8 байт | ~±1.7e308 (15 знаков) |
| `long double` | ≥ `double` | 8, 12 или 16 байт | зависит от платформы |
| `void` | — | 0 байт | "ничего", но `void*` — указатель (размер как `int*`) |

> ⚠️ `char` — это **минимальная адресуемая единица памяти**, и **всегда 1 байт**, даже если байт не 8 бит (на редких системах — 9 или 16 бит).

---

## Типы с фиксированным размером (`<stdint.h>`)

Эти типы **гарантированно имеют указанный размер**, если они поддерживаются платформой.

| Тип | Размер (байт) | Диапазон |
|------|----------------|---------|
| `int8_t` / `uint8_t` | 1 | -128…127 / 0…255 |
| `int16_t` / `uint16_t` | 2 | -32,768…32,767 / 0…65,535 |
| `int32_t` / `uint32_t` | 4 | ±2.1e9 / 0…4.2e9 |
| `int64_t` / `uint64_t` | 8 | ±9.2e18 / до 1.8e19 |

> 💡 Эти типы есть **только при `#include <stdint.h>`**.

---

## Минимальные и "быстрые" типы (`<stdint.h>`)

| Тип | Описание |
|------|---------|
| `int_least8_t` | Наименьший тип ≥8 бит (может быть больше) |
| `int_fast8_t` | Самый быстрый тип ≥8 бит (часто `int`) |
| `intmax_t` | Самый большой целочисленный тип (обычно `long long`) |
| `uintptr_t` | Целое, в которое можно безопасно сохранить указатель |

---

## Указатели

Размер указателя **зависит от разрядности системы**:

| Указатель | 32-битная система | 64-битная система |
|----------|-------------------|-------------------|
| `int*`, `char*`, `void*` и др. | 4 байта | 8 байт |

> ⚠️ Все указатели одного вида (на данные) обычно одинаковы по размеру.

---

## Пример: как проверить размер на своей системе

```c
#include <stdio.h>
#include <stdint.h>

int main() {
  printf("sizeof(char) = %zu байт\n", sizeof(char));
  printf("sizeof(int) = %zu байт\n", sizeof(int));
  printf("sizeof(long) = %zu байт\n", sizeof(long));
  printf("sizeof(void*) = %zu байт\n", sizeof(void*));
  printf("sizeof(uint32_t) = %zu байт\n", sizeof(uint32_t));
  return 0;
}
```

> 🔍 Используй `%zu` для `size_t` (тип, возвращаемый `sizeof`).

## Краткая сводка

| Категория | Типы | Размер (типичный) |
|----------|------|-------------------|
| **1 байт** | `char`, `uint8_t`, `int8_t` | 1 |
| **2 байта** | `short`, `uint16_t`, `int16_t` | 2 |
| **4 байта** | `int`, `float`, `uint32_t`, `int32_t` | 4 |
| **8 байт** | `long long`, `double`, `uint64_t`, `int64_t` | 8 |
| **8/16 байт** | `long double` | 8, 12 или 16 |
| **4 или 8 байт** | `long`, `void*` | зависит от ОС и архитектуры |

---

## 💡 Рекомендации

- Используй **`uint8_t`, `int32_t` и т.д.**, если важен **точный размер**.
- Используй **`int`, `long long`** для общих вычислений.
- Используй **`size_t`** для размеров, индексов, счётчиков в циклах (возвращается `sizeof`, `strlen` и др.).
- Не полагайся на размер `int` или `long` — он **нестабилен** между платформами.

## Почему нужны `uint8_t`, `int32_t` и т.д.?

Потому что **обычные типы в C не гарантируют фиксированный размер**!

Например:
- `int` может быть 16, 32 или даже 64 бита — зависит от платформы
- `long` — тоже варьируется

А вот типы из `<stdint.h>` **гарантируют точный размер**:

| Тип        | Размер (бит) | Диапазон                    |
|------------|-------------|------------------------------|
| `uint8_t`  | 8           | 0 … 255                      |
| `int8_t`   | 8           | -128 … 127                   |
| `uint16_t` | 16          | 0 … 65,535                   |
| `int16_t`  | 16          | -32,768 … 32,767             |
| `uint32_t` | 32          | 0 … 4,294,967,295            |
| `int32_t`  | 32          | -2,147,483,648 … 2,147,483,647 |
| `uint64_t` | 64          | 0 … 18,446,744,073,709,551,615 |
| `int64_t`  | 64          | до ±9 квинтиллионов          |

---

### Пример использования `uint8_t`

```c
#include <stdio.h>
#include <stdint.h>

int main() {
  uint8_t age = 25;
  uint16_t population = 65535;

  printf("Возраст: %u\n", age);
  printf("Население: %u\n", population);

  return 0;
}
```

> ⚠️ При печати используй правильные спецификаторы формата:
> - `%u` — для `unsigned int` (и `uint8_t`, `uint16_t` — они обычно promoted к `int`)
  > - `%lu` — для `uint32_t`, если нужно
  > - Для точности — лучше использовать макросы из `<inttypes.h>`

  ---

### Как правильно печатать типы из `<stdint.h>`?

  Используй заголовок:
  ```c
#include <inttypes.h>
  ```

  Он даёт **спецификаторы формата**:

  ```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

  int main() {
    uint8_t  a = 100;
    uint32_t b = 1234567890;
    int64_t  c = -9876543210123LL;

    printf("a = %" PRIu8 "\n", a);     // PRIu8 — печать uint8_t
    printf("b = %" PRIu32 "\n", b);
    printf("c = %" PRId64 "\n", c);    // PRId64 — для int64_t

    return 0;
  }
```

📌 `PRIu8`, `PRIu32`, `PRId64` — это **макросы**, которые подставляют правильный спецификатор (`%u`, `%lu`, `%lld` и т.д.) в зависимости от платформы.


### Когда использовать `uint8_t`?

✅ Используй, когда:
- Нужен **ровно 1 байт** (например, для бинарных данных, буферов, сетевых пакетов)
  - Работаешь с **драйверами, embedded, протоколами**
  - Хочешь **переносимости** между платформами
- Экономишь память (в массивах из тысяч элементов)

  Пример:
  ```c
  uint8_t buffer[256]; // буфер из 256 байт
  ```
