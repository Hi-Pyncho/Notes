`memcpy` позволяет копировать блоки памяти из одного места в другое. Рассмотрим подробно, что это такое, как она работает и какие есть нюансы.

## Объявление функции

```c
void *memcpy(void *dest, const void *src, size_t n);
```

- `dest` — указатель на область памяти, куда будет скопировано содержимое.
- `src` — указатель на область памяти, откуда будет копироваться содержимое.
- `n` — количество байтов, которые нужно скопировать.
- Возвращает указатель на `dest`.

Функция объявлена в заголовочном файле `<string.h>`.

---

## Как работает

`memcpy` побайтово копирует `n` байт из памяти по адресу `src` в память по адресу `dest`. При этом **не интерпретирует** данные — она просто копирует байты "как есть", что делает её универсальной для копирования любых типов данных: массивов, структур, чисел и т.д.

---

## Примеры использования

### 1. Копирование массива
```c
#include <stdio.h>
#include <string.h>

int main() {
  int src[] = {1, 2, 3, 4, 5};
  int dest[5];

  memcpy(dest, src, sizeof(src));

  for (int i = 0; i < 5; i++) {
      printf("%d ", dest[i]);
  }
  // Вывод: 1 2 3 4 5

  return 0;
}
```

### 2. Копирование структуры
```c
#include <stdio.h>
#include <string.h>

struct Person {
  char name[20];
  int age;
};

int main() {
  struct Person p1 = {"Alice", 25};
  struct Person p2;

  memcpy(&p2, &p1, sizeof(struct Person));

  printf("Name: %s, Age: %d\n", p2.name, p2.age);
  // Вывод: Name: Alice, Age: 25

  return 0;
}
```

### 3. Копирование строки (в байтах)
```c
char src[] = "Hello";
char dest[10];

memcpy(dest, src, strlen(src) + 1);  // +1 чтобы скопировать '\0'
```

## Важные особенности и предупреждения

### 1. **Перекрывающиеся области памяти — опасны!**
Если области памяти `src` и `dest` перекрываются (например, вы копируете часть массива на себя же), `memcpy` **не гарантирует корректную работу**.

❌ Плохо:
```c
int arr[] = {1, 2, 3, 4, 5};
memcpy(arr + 1, arr, 3 * sizeof(int)); // Перекрытие — UB или неправильный результат
```

✅ Вместо этого используйте `memmove`, которая **безопасна при перекрытии**:
```c
memmove(arr + 1, arr, 3 * sizeof(int)); // OK
```

### 2. **Нет проверки на null**
Если передать `NULL` в `src` или `dest`, поведение неопределено (обычно — segmentation fault).

### 3. **Нет проверки размера буфера**
Программист сам отвечает за то, чтобы в `dest` было достаточно места. Переполнение буфера — частая ошибка.

### 4. **Копирует ровно `n` байт, даже если данные короче**
Например, при копировании строки важно не забыть про завершающий ноль.

---

## Отличие от `strcpy`, `memmove`, `memset`

| Функция     | Назначение |
|------------|-----------|
| `strcpy`   | Копирует строку (до `\0`), только для строк |
| `memcpy`   | Копирует `n` байт, для любых данных, **не для перекрывающихся областей** |
| `memmove`  | То же, что `memcpy`, но **безопасно при перекрытии** |
| `memset`   | Заполняет память заданным байтом (например, обнуление) |

---

## Безопасность и современные альтернативы

В некоторых системах (особенно в Windows) рекомендуют использовать "безопасные" версии, например `memcpy_s`, но это **не стандарт C**, а часть стандарта ISO/IEC TR 24731 (и не везде доступно).

```c
errno_t memcpy_s(void *dest, rsize_t destsz, const void *src, rsize_t count);
```

Но большинство разработчиков по-прежнему используют `memcpy`, просто тщательно контролируя размеры.

---

## Подводя итог

- `memcpy` — мощный и быстрый способ копирования памяти.
- Универсальный: работает с любыми типами данных.
- Не проверяет границы — **ответственность на программисте**.
- **Не используйте при перекрывающихся областях** — лучше `memmove`.
- Всегда указывайте правильный размер (`sizeof`, `strlen + 1` и т.п.).
