**`enum`** — это тип данных в C, который позволяет задавать **именованные целочисленные константы**. Он используется для повышения читаемости и удобства кода, когда нужно работать с набором связанных значений.

---

### Синтаксис объявления `enum`

```c
enum name {
  elem1,
  elem2,
  // ...
};

printf("%d\n", elem1) // 0
```

использовать `typedef` для удобства:

```c
typedef enum {
  RED,
  GREEN,
  BLUE
} Color;

Color my_color = GREEN;
```

---

### Как работают значения в `enum`?

По умолчанию:
- Первый элемент получает значение `0`
- Каждый следующий — на 1 больше предыдущего

Пример:

```c
enum colors {
  RED,     // 0
  GREEN,   // 1
  BLUE     // 2
};
```

Но можно явно задавать значения:

```c
enum status {
  OFF = 0,
  ON = 1,
  PENDING = 5,
  ERROR = -1
};
```

Можно и так:

```c
enum numbers {
  ONE = 1,
  TWO,      // 2
  THREE,    // 3
  TEN = 10,
  ELEVEN    // 11
};
```

---

### Особенности и нюансы

- `enum` — это **целочисленный тип**. Внутри он хранится как `int` (или другой целый тип, зависит от компилятора и значений).
- Можно присваивать переменной `enum` любое целое значение, даже если его нет в списке:
```c
enum colors c = 999; // Компилятор может предупредить, но не запрещает!
```
- Можно сравнивать с числами:
```c
if (c == 2) { ... }
```

- Имена в `enum` должны быть уникальными в пределах области видимости (как и обычные идентификаторы).

---

### Пример использования

```c
#include <stdio.h>

typedef enum {
  SMALL,
  MEDIUM,
  LARGE
} Size;

int main() {
  Size shirt = MEDIUM;

  switch (shirt) {
    case SMALL:
      printf("Размер: S\n");
      break;
    case MEDIUM:
      printf("Размер: M\n");
      break;
    case LARGE:
      printf("Размер: L\n");
      break;
    default:
      printf("Неизвестный размер\n");
  }

  printf("MEDIUM = %d\n", MEDIUM); // Выведет: 1

  return 0;
}
```

---

### `enum` vs `#define` vs `const`

| Способ | Преимущества | Недостатки |
|-------|-------------|----------|
| `#define RED 0` | Лёгкий, старый способ | Нет типа, не отлаживается |
| `const int RED = 0;` | Типизировано | Много строк, не группирует |
| `enum { RED, GREEN }` | Группировка, тип, читаемость | Только целые числа |

`enum` — лучший выбор для набора связанных целочисленных констант.
