## Что такое `union`?

**`union`** — это специальный тип данных в C, который позволяет **хранить разные типы данных в одном и том же участке памяти**, но **только одно значение в один момент времени**.

---

### Синтаксис объявления `union`

```c
union имя_объединения {
  тип1 поле1;
  тип2 поле2;
  // ...
};
```

Пример:

```c
union Data {
  int i;
  float f;
  char str[20];
};
```

Теперь можно создать переменную:

```c
union Data data;
```

---

### Как работает память в `union`?

Размер `union` равен **размеру самого большого его члена**.

В примере выше:
- `int` — 4 байта
- `float` — 4 байта
- `char[20]` — 20 байт

➡️ Значит, `sizeof(data)` будет **20 байт**.

Но **все поля начинаются с одного и того же адреса** — они **перекрываются в памяти**.

---

### Пример использования

```c
#include <stdio.h>
#include <string.h>

union Data {
  int i;
  float f;
  char str[20];
};

int main() {
  union Data data;

  data.i = 10;
  printf("data.i: %d\n", data.i);  // 10

  data.f = 3.14;
  printf("data.f: %.2f\n", data.f);  // 3.14
                                     // ⚠️ data.i теперь "битый" — память перезаписана!

  strcpy(data.str, "Hello");
  printf("data.str: %s\n", data.str);  // Hello
                                       // ⚠️ data.f и data.i теперь мусор!

  return 0;
}
```

```c
typedef union str {
  int integer;
  char string;
} str_t;

int main() {
  str_t data;
  data.integer = 65;
  printf("%c\n", data.string) // A
}
```

```c
typedef union Color {
  struct {
    uint8_t r;
    uint8_t g;
    uint8_t b;
    uint8_t a;
  } components;
  uint32_t rgba;
} color_t;

int main() {
  color_t color = {
    .components = {
      .a = 22,
      .b = 111,
      .g = 55,
      .a = 255
    }
  };

  printf("%u\n", color.rgba);
}
```

📌 **Важно:** когда вы пишете в одно поле — **предыдущие данные теряются**, потому что все поля делят одну и ту же память.

---

### Зачем нужны `union`?

1. **Экономия памяти**
- Если вы точно знаете, что в один момент будет использоваться только одно поле, `union` экономит память по сравнению с `struct`.

```c
struct S { int a; float b; };  // 8 байт (или больше)
union  U { int a; float b; };  // 4 байта
```

2. **Работа с "сырыми" данными**
- Можно использовать `union`, чтобы интерпретировать одни и те же байты по-разному.

Пример: доступ к байтам числа:

```c
union {
  int num;
  char bytes[4];
} u;

u.num = 0x12345678;
printf("Byte 0: %02X\n", u.bytes[0]); // зависит от порядка байт (endianness)
```

3. **Сериализация / сетевые протоколы**
- Удобно для упаковки/распаковки данных.

4. **Реализация "variant"-типов (типы-суммы)**
- В C нет `std::variant` как в C++, но `union` + тег (тип) позволяют сделать нечто подобное.

---

### Безопасное использование: `union` с тегом

Чтобы не потерять, какое поле сейчас "активно", часто используют `enum` + `struct` + `union`:

```c
#include <stdio.h>

enum Type {
  INT,
  FLOAT,
  STRING
};

struct SafeData {
  enum Type type;
  union {
    int i;
    float f;
    char str[20];
  } value;
};

void printData(const struct SafeData *data) {
  switch (data->type) {
    case INT:
      printf("Integer: %d\n", data->value.i);
      break;
    case FLOAT:
      printf("Float: %.2f\n", data->value.f);
      break;
    case STRING:
      printf("String: %s\n", data->value.str);
      break;
  }
}

int main() {
  struct SafeData data;

  data.type = INT;
  data.value.i = 42;
  printData(&data);

  data.type = FLOAT;
  data.value.f = 3.14;
  printData(&data);

  return 0;
}
```

Это — **безопасный способ** работать с `union`.

---

### Ограничения и подводные камни

- ❌ **Нет автоматической проверки**, какое поле активно.
- ❌ **Обращение к неактивному полю** — **неопределённое поведение** (UB).
- ❌ Нельзя хранить несколько значений одновременно.
- ❌ Нельзя включать в `union` поля с конструкторами (в C++ — да, в C — нет проблем, т.к. C не имеет конструкторов).

---

### `union` vs `struct`

| Характеристика       | `struct`                     | `union`                          |
|----------------------|------------------------------|----------------------------------|
| Память               | Сумма всех полей             | Размер самого большого поля     |
| Доступ               | Все поля независимы          | Только одно поле активно        |
| Перекрытие полей     | Нет                          | Да, все поля на одном адресе     |
| Использование        | Хранение нескольких данных  | Экономия памяти, интерпретация   |

---

### Подсказка: когда использовать `union`?

✅ Используй `union`, если:
- Нужно экономить память.
- Ты точно знаешь, что в один момент будет использоваться только одно поле.
- Тебе нужно "сырое" представление данных (например, битовые манипуляции).

🚫 Не используй (или будь осторожен), если:
- Нужно хранить несколько значений одновременно.
- Нет контроля над тем, какое поле активно.

---

### Вывод

`union` — мощный, но **опасный** инструмент. Он позволяет эффективно использовать память и работать с данными на низком уровне, но требует **осознанного управления состоянием**.

Если использовать `union` вместе с тегом (`enum`), можно создать безопасный "тип-сумму", что очень полезно в системном программировании, драйверах, протоколах и embedded-разработке.
