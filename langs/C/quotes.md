__Одинарные кавычки ' ' - символьный литерал__
```c
char c = 'A';    // один символ
```
Особенности:
- Содержит ровно один символ (исключение: escape-последовательности)
- Имеет тип int (но обычно присваивается в char)
- Размер: 4 байта (как int)
- Значение: ASCII-код символа

```c
printf("%c\n", 'A');    // A
printf("%d\n", 'A');    // 65 (ASCII-код)
printf("%zu\n", sizeof('A')); // 4 (размер int)
```

__Двойные кавычки " " - строковый литерал__
```c
char *str = "Hello";    // строка
```
Особенности:
- Содержит последовательность символов + завершающий \0
- Имеет тип char[] (но decay to char*)
- Размер: длина строки + 1 байт для \0
- Хранится в read-only памяти

```c
printf("%s\n", "Hello");    // Hello
printf("%zu\n", sizeof("Hello")); // 6 (5 символов + \0)
printf("%p\n", "Hello");    // адрес в памяти
```

| Характеристика | Одинарные `' '` | Двойные `" "` |
|----------------|-----------------|---------------|
| **Тип** | `int` | `char[]` (decays to `char*`) |
| **Размер** | 4 байта (как `int`) | Длина строки + 1 (`\0`) |
| **Содержимое** | Один символ | Последовательность символов + `\0` |
| **Использование** | `char c = 'A';` | `char *s = "ABC";` |
| **Память** | Значение в коде | Read-only сегмент (.rodata) |
| **Пример** | `'A'` → 65 | `"A"` → `{'A', '\0'}` |

Важные отличия
1. Размер в памяти

```c
printf("%zu\n", sizeof('A'));   // 4 (int)
printf("%zu\n', sizeof("A"));   // 2 (char[2]: 'A' + '\0')
```

2. Многобайтовые символы
```c
// Одинарные - только один символ:
// char c = 'AB';  // ОШИБКА!

// Двойные - строка любой длины:
char *s = "ABCD";  // OK

```

3. Escape-последовательности
```c
char newline = '\n';    // один символ (код 10)
char *str = "\n";       // строка из двух байтов: {10, 0}

```

4. Адресная арифметика
```c
char c = 'A';
char *s = "A";

printf("%p\n", &c);     // адрес переменной c
printf("%p\n", s);      // адрес строкового литерала
// printf("%p\n", &'A'); // ОШИБКА: у литерала нет адреса
```

Частые ошибки
Неправильно:
```c
char c = "A";    // ОШИБКА: пытаемся char = char*
char *s = 'A';   // ОШИБКА: пытаемся char* = int
```
Правильно:
```c
char c = 'A';    // OK: char = int (ASCII код)
char *s = "A";   // OK: char* = char[]
```
